## About

Authiva is a lightweight, server-side authentication plugin for Minecraft servers.

It provides a simple authentication system without requiring any client-side mods.

## Features

- Player registration and login
- Password management
- Login protection
- Authentication sessions
- SQLite storage
- Configurable security
- Lightweight server-side implementation
- No client-side mod required

## Commands

### Player Commands

```text
/register <password> <confirmPassword>
/login <password>
/logout
/changepassword <currentPassword> <newPassword>
/unregister <password>
```

### Admin Commands

```text
/authiva help
/authiva info
/authiva list
/authiva logout
/authiva setpassword
/authiva unregister
/authiva delete
/authiva reload
```

## Installation

1. Download the latest `Authiva.jar`.
2. Place the `.jar` file inside your server's `plugins` folder.
3. Start or restart your Minecraft server.
4. Configure Authiva to match your server's requirements.
